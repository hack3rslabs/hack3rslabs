`Next.js` `Node.js` `PostgreSQL` `Stripe` `Azure` `OWASP Audit` `CI/CD`

`TypeScript` `React` `Node.js` `PostgreSQL` `Azure` `RBAC` `Security Hardened`

**Custom web platform** for a cultural arts organisation — event management, registrations, media gallery, and content management system. Responsive, performant, and secured before handoff.

`React` `Node.js` `MySQL` `Cloud Deployment` `Security Audit`

---

### 🏢 ERP Application — Enterprise Resource Planning
**Multi-module ERP** covering inventory, procurement, sales, accounts, HR, and reporting — built for SME operations. End-to-end delivery: requirements gathering → architecture → development → UAT → security audit → production deployment.

`TypeScript` `Node.js` `PostgreSQL` `Docker` `Azure` `Role-Based Access`

### 🧾 Indian GST Billing Application
**GST-compliant billing and invoicing platform** built to Indian tax standards — multi-rate GST computation, e-invoice generation, GSTR report exports, and client/vendor ledger management.

`TypeScript` `Node.js` `MySQL` `PDF Generation` `GST API Integration`

### 🤖 AI Automation Suite — n8n + AI Agents
